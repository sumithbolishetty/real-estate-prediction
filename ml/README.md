# ML pipeline

The training target is `price`. The eight input groups are `location`, `area` (square feet), `bedrooms`, `bathrooms`, `property_type`, `parking`, `property_age` (years), and `amenities` (allowlisted multi-hot values). The single sklearn pipeline handles numeric pass-through, one-hot categorical encoding with `handle_unknown="ignore"`, and multi-hot amenities, and it is reused for prediction.

`../data/raw/sample_properties.csv` is the existing project-created demo dataset: 42 rows, 9 columns, no missing rows, no exact duplicates, and no rows removed by current cleaning checks. It is not independently verified real-market evidence. No larger compatible dataset exists in the project. Training compares a mean-price baseline, Random Forest, Extra Trees, and Hist Gradient Boosting using identical shuffled five-fold cross-validation. It selects the regressor with the lowest mean CV MAE, then refits on all valid rows. MAE, RMSE, R², fold variation, category/feature analyses, and grouped feature importance are generated from those runs. IQR outliers remain unless a concrete data-quality error is found. Invalid/missing rows, blank required categories, non-finite/nonnumeric numeric values, and constraint violations are removed and counted.

The data contains four numerical inputs and four categorical/multi-label inputs. The numeric inputs have 40 distinct area values, 4 bedroom counts, 4 bathroom counts, and 19 ages. There are 7 locations, 3 property types, and 2 parking values. The 14 observed amenity bundles resolve to 8 individual amenity flags. Price has three high-side IQR flags; they correspond to larger premium home types and are retained. The dataset is small and demo-only; cross-validation results and tree importance have high uncertainty and do not represent market accuracy or causation.

Training writes the model pipeline to `../artifacts/model/price_pipeline.joblib`, detailed version/evaluation/importance metadata to `../artifacts/model/model_metadata.json`, supported values to `../artifacts/preprocessing/metadata.json`, and analysis reports to `../data/processed/`.

The current five-fold result selects Extra Trees by lowest mean CV MAE: ₹3,768,013 ± ₹1,698,884. Random Forest is ₹4,431,423 ± ₹2,608,040 and Hist Gradient Boosting is ₹8,116,410 ± ₹2,180,268; the mean-price baseline is ₹8,116,410 ± ₹2,180,268. These fold standard deviations and the 42-row sample make the performance estimate uncertain. Grouped all-data tree importance is recorded in the evaluation report and must not be interpreted causally.

From the project root, create and activate the isolated environment: `cd ml`, `python3 -m venv .venv`, `source .venv/bin/activate`, `python -m pip install -r requirements.txt`. While inside `ml/`, run `python train.py`, `python evaluate.py`, or `python predict.py`. Test from `ml/` with `python -m pytest tests` after training and installing pytest (`python -m pip install pytest`).
